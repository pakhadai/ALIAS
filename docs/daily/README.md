# Денний журнал змін

**Мета:** за ~30 секунд зрозуміти, що зроблено сьогодні, без читання всього [`CHANGELOG.md`](../../CHANGELOG.md).

## Правила

- **Часовий пояс:** Europe/Kyiv.
- **Один календарний день — один файл:** `YYYY-MM-DD.md`.
- **Новий день — новий файл;** не дописувати вчорашній файл наступного дня.
- **`CHANGELOG.md`** — накопичувальний релізний лог; **`docs/daily/`** — оперативний щоденник сесій.
- Після сесії з змінами в `packages/` або `docs/` — додай хоча б один блок `## Зміни` (див. шаблон у сьогоднішньому файлі).

## Шаблон `YYYY-MM-DD.md`

```markdown
# MOVLI Master — YYYY-MM-DD
> Швидкий огляд дня. Деталі релізів → CHANGELOG.md

## Підсумок (1–3 речення)
...

## Зміни
### [HH:MM] — Короткий заголовок
- **Тип:** feat | fix | docs | refactor | chore
- **Область:** client | server | shared | infra | docs
- **Файли:** `path/a.ts`, `path/b.ts`
- **Що:** ...
- **Чому:** ...
- **Ризики / TODO:** ...

## Відкриті питання
- ...

## Doc sync
- [ ] README  [ ] PROJECT_STATE  [ ] CHANGELOG [Unreleased]
```

## Хто веде

Людина або агент **movli-steward** наприкінці сесії (див. [`docs/CONTRIBUTING.md`](../CONTRIBUTING.md)).
